ကိုယ်သိချင်တဲ့ အကြောင်းအရာကို Package ရွေးပြီး Messenger ကနေ မေးနိုင်ပါတယ်။ အဆင့် ၅ ဆင့်တည်းနဲ့ ပြီးပါတယ်။

Messenger မှ တိုက်ရိုက် ဖြေကြားမှု အဖြေ ၁၂ နာရီမှ ၄၈ နာရီအတွင်း KPay / Wave Pay
01

မေးမြန်းရန် ပေးပို့နည်း အဆင့်ဆင့်

  1. 1

    Package ရွေးပါ

    အောက်က Package ၅ ခုထဲက ကိုယ့်မေးခွန်း အရေအတွက်နဲ့ ကိုက်တဲ့ တစ်ခုကို ရွေးပါ။

  2. 2

    မေးခွန်း + နာမည် / မွေးနေ့ ပြင်ဆင်ပါ

    မေးချင်တဲ့ မေးခွန်းကို ရှင်းရှင်းလင်းလင်း ရေးပြီး နာမည် နဲ့ မွေးနေ့ ကိုပါ တစ်ပါတည်း ပြင်ထားပါ။

  3. 3

    ဟောခ ပေးချေပါ

    KPay / Wave Pay — ကြိုက်ရာ တစ်ခုခုနဲ့ ပေးချေပြီး ငွေလွှဲပြေစာ (Screenshot) ကို သိမ်းထားပါ။ အကောင့် အချက်အလက်ကို Messenger မှာ ပေးပို့ရပါမယ်။

  4. 4

    Messenger ကနေ ပို့ပေးပါ

    ငွေလွှဲပြေစာ + မေးခွန်း + နာမည် / မွေးနေ့ ကို StarFish Tarot Page ရဲ့ Messenger ကနေ တစ်စုတည်း ပို့ပေးပါ။

  5. 5

    အဖြေ စောင့်ပါ

    ဟောစာတမ်းကို ၁၂ နာရီမှ ၄၈ နာရီ အတွင်း Messenger ကနေပဲ ပြန်ပို့ပေးပါမယ်။

02

Package ရွေးချယ်ရန်

နှိပ်ပြီး ရွေးထားလို့ရပါတယ် — ရွေးထားတဲ့ Package က အောက်က ပို့ရမယ့် ပုံစံထဲ အလိုအလျောက် ပါသွားပါမယ်။

မေးခွန်း ၁ ခု ၅,၀၀၀ကျပ် မေးခွန်းပေါ်မူတည်၍ ၁ ကတ် မှ ၃ ကတ်ထိ ဆွဲပြီး သေချာစွာ ဟောပေးမည်။
အဓိက ⭐ မေးခွန်း ၃ ခု ၁၂,၀၀၀ကျပ် မေးခွန်းတစ်ခုချင်းစီ သုံးသပ်ကြည့်ပြီး သေချာစွာ ဟောပေးပါမည်။
Love Package ၁၅,၀၀၀ကျပ် မေးခွန်းပေါ်မူတည်၍ အချစ်ရေး သီးသန့် — နှစ်ဦးကြား ဆက်ဆံရေး၊ ခံစားချက်နဲ့ လမ်းကြောင်းကို အသေးစိတ် ကြည့်ပေးပါမည်။
Deep Reading ၂၀,၀၀၀ကျပ် မေးခွန်း ၅–၆ ခု — အခြေအနေ အစုံကို နက်နက်ရှိုင်းရှိုင်း သုံးသပ် ဟောပေးမည်။
တစ်နှစ်စာ Package ၃၀,၀၀၀ကျပ် တစ်နှစ်လုံးရဲ့ အဓိက လမ်းကြောင်း + ၁၂ လစာ ဇယား — ကိုယ့်အတွက် သီးသန့် ဟောထားတဲ့ ဟောစာတမ်း တစ်စောင် တစ်ခါတည်း ပို့ပေးမည်။

ရွေးထားသော Package — မေးခွန်း ၃ ခု · ၁၂,၀၀၀ ကျပ်

03

Messenger မှာ ပို့ပေးရမယ့် အချက်အလက်

  • မေးခွန်း — သိချင်တဲ့ အကြောင်းအရာကို ရှင်းရှင်းလင်းလင်း ရေးပေးပါ
  • နာမည် — ဟောကြားမှု ခံယူမယ့်သူရဲ့ နာမည်
  • မွေးနေ့ — မွေးသက္ကရာဇ် အပြည့်အစုံ
  • ရွေးထားတဲ့ Package — ဘယ် Package ယူထားလဲ ဆိုတာ ရွေးပါ။
  • ငွေလွှဲပြေစာ — KPay / Wave Pay ပေးချေထားတဲ့ Screenshot

ပို့ရမယ့် ပုံစံလွယ်ကူရန် — ဒီမှာပဲ တစ်ခါတည်း ဖြည့်ပြီး Copy ယူနိုင်ပါတယ်

စာရေးနေရင်း ပြောင်းချင်ရင် အပေါ် ပြန်တက်စရာမလိုဘဲ ဒီမှာတင် နှိပ်ပြီး ရွေးနိုင်ပါတယ်။

(ငွေလွှဲပြေစာ Screenshot ကိုလည်း တွဲပို့ပေးပါ)

04

မေးခွန်း ကောင်းကောင်း မေးနည်း

✓ ကောင်းတဲ့ မေးခွန်း ပုံစံ

  • နောက် ၃ လအတွင်း အလုပ်ပြောင်းသင့်လား၊ ဘာတွေ သတိထားရမလဲ
  • ဒီလူနဲ့ ဆက်ဆံရေး ရှေ့ဆက် ဘယ်လို ဖြစ်လာနိုင်လဲ
  • အခု စီးပွားရေး အသစ် စဖို့ အချိန် သင့်တော်ပြီလား

✕ မှုန်ဝါးတဲ့ မေးခွန်း ပုံစံ

  • အနာဂတ် ဘယ်လို ရှိလဲ
  • ကံကောင်းမှာလား
  • ဘာတွေ ဖြစ်လာမှာလဲ
  • မေးခွန်း တစ်ခု = အကြောင်းအရာ တစ်ခု — အကြောင်းအရာ နှစ်ခု သုံးခု ရောမေးရင် အဖြေလည်း ရောသွားတတ်ပါတယ်။
  • အချိန် သတ်မှတ်ပေးပါ — “နောက် ၃ လ” “ဒီနှစ်အတွင်း” လို ထည့်မေးရင် အဖြေ ပိုတိကျ ပိုရှင်းပါတယ်။
  • အခြေအနေ အကျဉ်း ထည့်ရေးပါ — ဘာကြောင့် ဒီမေးခွန်း မေးတာလဲ ဆိုတဲ့ နောက်ခံ နည်းနည်း ပါရင် ဟောစာ ပိုထိရောက်ပါတယ်။
05

မဟောပေးတဲ့ အရာတွေ

ဆေးကုသမှု / ကျန်းမာရေးရောဂါ စစ်ဆေးမှုနဲ့ ကုသမှု ဆုံးဖြတ်ချက်တွေ — ဆရာဝန်နဲ့သာ တိုင်ပင်ပါ
တရားရုံး / ဥပဒေ အမှုအမှုရဲ့ အနိုင်အရှုံး အဖြေမျိုးတွေ မဟောပေးပါဘူး
ထီ / လောင်းကစား ဂဏန်းထီဂဏန်း၊ ချဲဂဏန်း ပေးတဲ့ ဟောကြားမှု မလုပ်ပါဘူး
သေဆုံးမှုသေဆုံးမယ့် အချိန် / ပုံစံနဲ့ ပတ်သက်တာတွေ မဟောပေးပါဘူး
Love Spells / ယတြာချစ်သူ ပြန်လာအောင် လုပ်ပေးတဲ့ မှော်ဆေး၊ ယတြာ လုပ်ပေးမှု မရှိပါဘူး
မေးခွန်း ထပ်ခါထပ်ခါ မေးတာမေးခွန်း တစ်ခုတည်းကို အဖြေ မကြိုက်လို့ ထပ်ခါထပ်ခါ ပြန်မေးတာမျိုး မဟောပေးပါဘူး
